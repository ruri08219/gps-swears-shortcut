The GPS's own excuse for sending the driver down the wrong road, written for make.fun's "The GPS Swears It Was a Shortcut" bounty: a concrete scene (a cul-de-sac with a lake at the end), one reversal (it was on purpose), and a landing final line (blame the map).

> I routed you into the cul-de-sac on purpose — the lake view beats your 9 a.m. meeting, and the map signed off on it. Blame the map, not me.

## Run it

```sh
python3 main.py
```

Writes the single excuse to `/output/entry.txt` (139 characters, one line, UTF-8). Standard library only.
